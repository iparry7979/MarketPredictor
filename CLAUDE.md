# PROJECT GOAL
    - Build a machine learning model that can predict price movements in betfair horse racing markets efficiently enough to be profitabe

# STEPS
    - Build a python project that reads betfair data files and converts them to snapshots that can be used to select features for the ML model
    - Feature engineering. Select features that will be used from the model. This may require some going back to refactor step 1 or looking at other sources
    - Training. Train the model
    - Connect the model to a solution that can perform back testing. I believe there are existing open source python solutions that can do this
    - Run back testing, analyzing results to see if profitable
    - If profitable move to actual betting with very small stakes and slowly increase
